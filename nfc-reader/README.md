# Lettore NFC per FilamentBox

Firmware per D1 Mini (ESP8266) + PN532 in SPI: legge tag OpenTag3D e Bambu Lab, assegna lo slot AMS con un pulsante e scrive i tag.

Apri `FilamentBoxNFC/FilamentBoxNFC.ino` con Arduino IDE e compila la sezione **CONFIGURA QUI** (rete WiFi, indirizzo del server, token del webhook).

Guida completa con collegamenti e librerie: [docs/lettore-nfc.md](../docs/lettore-nfc.md).
