💾 Backup dei dati

Esporta bobine, posizioni, consumi e fatture importate in un file JSON (senza token né chiavi). Puoi ripristinarlo qui o in un'altra edizione di FilamentBox. Nell'edizione Lite i dati vivono solo in questo browser: fai un backup ogni tanto.

🏠 Connessione Home Assistant

Necessario per la sincronizzazione AMS. Inserisci l'URL interno di HA e un Long-Lived Access Token (Profilo → Token di accesso a lungo termine).

Entità della stampante in Home Assistant

I nomi dipendono dal nome della stampante e dalla lingua di HA. Li trovi in HA → Strumenti per sviluppatori → Stati. Lascia vuoto per il valore predefinito.

📡 AMS Sync da Home Assistant

Legge i filamenti attualmente caricati nell'AMS direttamente dai sensori HA e ti guida nel bindarli alla libreria. Usa questo quando inserisci nuove bobine.

📟 Lettore NFC fisico

Stato del lettore D1 Mini + PN532 montato vicino alla stampante — nessun bisogno di scollegare nulla per verificare che sia acceso e funzionante.
